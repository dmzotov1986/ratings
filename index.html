Рейтинги для турниров

Предлагаемая формула на основе существующих.
Начальный рейтинг 0, за каждый выигрыш у равного +1, проигрыш -1, ничья +0.
При игре с неравным соперником пропорционально обычной формуле для рейтингов.
Похоже, такого рода рейтинги не подходят для круговых турниров.
Скорее, для турниров, где игры ведутся преимущественно с равными соперниками.
