# ratings
Рейтинги для турниров. Предлагаемая формула на основе существующих. Начальный рейтинг 0, за каждый выигрыш у равного +1, проигрыш -1, ничья +0. Однако, при игре с неравным соперником пропорционально формуле Эло. Ещё исследовать, модифицировать можно, но, когда будет готово, то можно пользоваться для проведения турниров. Нужно сделать вспомогательный класс с интерфейсом для использования. Особенно, есть вопросы по поводу коэффициентов в формуле и их значения, а также спортивных разрядов – как должны выглядеть, для самоидентификации. Исследовать хотя бы прогоном (многократным) кругового турнира с соперниками, всегда выигрывающими у более низшего номера в списке.
