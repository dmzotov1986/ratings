# ratings
[https://dmzotov1986.github.io/ratings/](https://dmzotov1986.github.io/ratings/)
Рейтинги для турниров. Предлагаемая формула на основе существующих. Начальный рейтинг 0, за каждый выигрыш у равного +1, проигрыш -1, ничья +0. Однако, при игре с неравным соперником пропорционально обычной формуле для рейтингов. Похоже, такого рода рейтинги не подходят для круговых турниров. Скорее, для турниров, где игры ведутся с преимущественно равными соперниками.
