# ratings
Рейтинги для турниров. Предлагаемая формула на основе существующих. Начальный рейтинг 0, за каждый выигрыш у равного +1, проигрыш -1, ничья +0. Однако, при игре с неравным соперником пропорционально формуле Эло. Ещё исследовать, модифицировать можно, но, когда будет готово, то можно пользоваться для проведения турниров.
